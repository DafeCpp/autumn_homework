## 1. Борувка: быстрое повторение и корректность

В каждой фазе все текущие компоненты выбирают минимальное исходящее ребро. Выборы вычисляются по компонентам **на начало фазы**; затем выбранные рёбра обрабатываются с помощью DSU. Если у компоненты нет исходящего ребра, она уже является компонентой исходного графа.

На примере A лекции 9 (`AB=1`, `CD=1`, `BC=2`, `DE=2`, `CE=3`, `AC=4`, `BD=5`, `BE=6`) первые выборы дают `AB`, `CD`, `DE`, затем `BC`. Сумма равна 6. Одно ребро может выбраться с двух сторон, но добавляется один раз.

### Почему выборы совместимы при равных весах

Зафиксируем **один общий строгий порядок** рёбер `(weight, id)`; каждая компонента выбирает минимум именно в этом порядке. Это лишь правило разрешения равенств, исходные веса не изменяются.

Рассмотрим задачу с бесконечно малым возмущением весов по этому порядку: для конечного графа можно выбрать достаточно малые различные поправки так, чтобы порядок рёбер стал строгим, а любое дерево минимального возмущённого веса было MST по исходным весам. В начале фазы выбранный лес содержится в некотором MST с возмущёнными весами. Разрез текущей компоненты не пересекает этот лес; её выбранное ребро — **единственный** минимум разреза, поэтому оно содержится в каждом MST возмущённого графа, совместимом с уже выбранным лесом. Значит, существует один MST, содержащий все выборы фазы одновременно.

На доске достаточно напомнить доказанную на прошлой паре теорему о разрезе и проговорить роль общего порядка. При произвольных независимых выборах равных рёбер без проверки объединения можно получить цикл: три компоненты треугольника из рёбер веса 1 могут совместно выбрать все три ребра. DSU отсекает повторы и рёбра, уже замыкающие цикл; код ниже дополнительно использует единый порядок.

### Фазы, код и сложность

```text
DSU = initialize(n)
answer = []
total = 0
while true:
    best = пустой массив из n записей
    for (u, v, w, id) in edges:
        a = DSU.find(u)
        b = DSU.find(v)
        if a == b: continue
        best[a] = min_по_порядку(best[a], (w,id,u,v))
        best[b] = min_по_порядку(best[b], (w,id,u,v))
    merged = 0
    for e in best:
        if e существует and DSU.unite(e.u, e.v):
            answer.push(e.id)
            total += e.w
            merged += 1
    if merged == 0: break
output(answer, total)  # минимальный остовный лес
```

Каждая неготовая компонента выбирает выход наружу; после фазы она объединена хотя бы с одной другой. Поэтому число неготовых компонент внутри каждой связной компоненты уменьшается как минимум вдвое. Фаз с объединениями `O(log(n + 1))`; для обнаружения завершения может понадобиться ещё один проход. Для несвязного графа получаем MSF, изолированные вершины не создают выходов.

При каждой фазе код делает `O(n + m)` операций инициализации, поиска и объединения; с DSU по рангу и сжатием грубая оценка времени — `O((n + m) α(n) log(n + 1))`, память `O(n + m)` вместе с входом и ответом. Для связного графа с `n > 1` это можно записать `O(m α(n) log n)`. Оценку `O(m log n)` нельзя выдавать за доказанную для этого кода, просто игнорируя стоимость DSU; она достижима при другой организации фаз с линейной обработкой каждой фазы.

| Алгоритм | Основная идея | Типичная оценка |
|---|---|---|
| Прим, массив | минимальное ребро из текущего дерева | `O(n² + m)` |
| Крускал, сортировка + DSU | рёбра в порядке веса | `O(n + m log(m + 1) + m α(n))` |
| Борувка, код выше | минимальный выход каждой компоненты за фазу | `O((n + m) α(n) log(n + 1))` |

Вопрос: «Рёбра, найденные в фазе, нужно выбирать повторно после каждого объединения?» Нет: минимум каждой компоненты ищем до объединений; затем DSU проверяет, не добавили ли уже соединяющее эти компоненты ребро.

## 2. Метрический TSP: 2-приближение

**Постановка.** Полный неориентированный граф, `w(u,v) >= 0`, симметричные веса и неравенство треугольника `w(u,v) <= w(u,x) + w(x,v)`. Ищем гамильтонов цикл минимальной стоимости `OPT`, то есть цикл, посещающий каждую вершину по одному разу и возвращающийся в начало. Для доски предполагаем `n >= 3`.

**Алгоритм:**

1. Построить MST `T`.
2. Продублировать каждое его ребро. Полученный связный мультиграф имеет все степени чётными, значит допускает эйлеров цикл.
3. Обойти этот цикл и при повторном посещении вершины пропустить её, заменяя несколько рёбер одним ребром полного исходного графа. Вернуться в начальную вершину.

Эквивалентно можно взять порядок первых посещений при DFS дерева и замкнуть его. При пропуске промежуточных вершин применяем неравенство треугольника, поэтому стоимость не увеличивается.

**Доказательство оценки:** из оптимального гамильтонова цикла удалим любое ребро. Останется остовное дерево, его стоимость не превышает `OPT` благодаря неотрицательности весов. Следовательно, `w(T) <= OPT`. Двойной обход стоит `2w(T)`, а сокращение повторов не увеличивает стоимость:

```text
стоимость ответа <= 2w(T) <= 2 OPT.
```

Это верхняя граница, а не обещание, что каждый ответ стоит ровно вдвое больше оптимума. Если граф неполон, прямого ребра для shortcut может не быть; если неравенство треугольника нарушено, shortcut может увеличить стоимость. Эти условия нельзя опускать.

**Пример на доске.** Четыре вершины на прямой с координатами `0,1,2,3`, вес — расстояние между координатами. MST — цепь веса 3. Двойной обход `0,1,2,3,2,1,0` стоит 6; после удаления повторных `2,1` получаем цикл `0,1,2,3,0` стоимости 6. Нижняя граница от MST равна 3; конкретный оптимум тоже равен 6.

Сложность: MST плюс линейный обход построенного дерева `O(n)` и `O(n)` памяти для порядка вершин; предполагаем доступ к весу любой пары за `O(1)`. Построение или хранение полного графа отдельно учитывается; для явного списка в нём `Θ(n²)` рёбер.
