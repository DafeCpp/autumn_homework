## Основные определения

- **Граф**: `G = (V, E)`, где `V` — множество вершин, `E` — множество рёбер.
- **Ориентированное ребро**: упорядоченная пара `(u, v)`. Наличие `(u, v)` не означает наличие `(v, u)`.
- **Неориентированное ребро**: неупорядоченная пара `{u, v}`.
- **Петля**: ребро из вершины в неё же.
- **Кратные рёбра**: несколько рёбер с одинаковыми концами.
- **Псевдограф**: граф, в котором разрешены петли и кратные рёбра.
- **Путь**: последовательность вершин, в которой соседние вершины соединены рёбрами нужного направления.
- **Достижимость**: `v` достижима из `u`, если существует путь из `u` в `v`.
- **Связный неориентированный граф**: между любыми двумя вершинами существует путь.
- **Компонента связности**: максимальное по включению связное множество вершин.
- **Слабая связность орграфа**: связность после удаления направлений рёбер.
- **Сильная связность орграфа**: для любых `u`, `v` существуют пути `u → v` и `v → u`.

Акцент: слово «максимальное» в определении компоненты обязательно. Любое связное подмножество ещё не является компонентой.

## Хранение графа

Обозначения: `n = |V|`, `m = |E|`.

| Представление | Память | Перебор соседей `v` | Проверка ребра `(u, v)` |
|---|---:|---:|---:|
| Список смежности | `O(n + m)` | `O(deg(v))` | обычно `O(deg(v))` |
| Матрица смежности | `O(n²)` | `O(n)` | `O(1)` |
| Список рёбер | `O(m)` | `O(m)` | `O(m)` |

Что помнить:

- список смежности обычно выбирают для разреженных графов и обходов;
- матрица удобна для плотных графов и частой проверки наличия ребра;
- в неориентированном графе ребро `{u, v}` записывается в списки `u` и `v`;
- сумма степеней неориентированного графа равна `2m`;
- сумма исходящих степеней ориентированного графа равна `m`.

## Компоненты связности

Один запуск DFS/BFS из `s` посещает ровно вершины, достижимые из `s`.

```text
components = 0
for v in vertices:
    if not visited[v]:
        DFS(v)
        components += 1
```

Почему это работает: новый обход начинается в ещё не посещённой компоненте и посещает её целиком; из неё невозможно перейти в другую компоненту.

Для ориентированного графа этот код сам по себе не находит компоненты сильной связности. Это тема одной из следующих лекций.

## DFS

Идея: идти по белым соседям максимально глубоко, затем возвращаться назад. Рекурсивный DFS использует стек вызовов; итеративный — явный стек.

### Цвета

- `WHITE` — вершина ещё не обнаружена;
- `GRAY` — обработка началась, вызов находится в стеке;
- `BLACK` — обработка вершины завершена.

Переходы цветов только такие: `WHITE → GRAY → BLACK`.

### Псевдокод

```text
DFS(u):
    color[u] = GRAY
    for v in adj[u]:
        if color[v] == WHITE:
            DFS(v)
    color[u] = BLACK
```

### Проверка наличия цикла

В ориентированном графе цикл найден, если DFS встречает ребро из текущей вершины в серую вершину: она ещё находится в стеке рекурсии. Рёбра в чёрные вершины цикла сами по себе не доказывают.

В неориентированном графе ребро обратно в родителя нужно пропустить. Ребро в любую другую уже посещённую вершину означает наличие цикла.

```text
DFS(u, parent):
    color[u] = GRAY
    for v in adj[u]:
        if color[v] == WHITE:
            if DFS(v, u):
                return true
        else if graph is directed and color[v] == GRAY:
            return true
        else if graph is undirected and v != parent:
            return true
    color[u] = BLACK
    return false
```

Обход нужно запускать из всех белых вершин: цикл может находиться не в компоненте выбранного старта. В неориентированном мультиграфе следует передавать идентификатор родительского ребра, иначе два параллельных ребра можно ошибочно принять за одно.

## BFS

Идея: обходить вершины слоями в порядке увеличения числа рёбер от старта. Для этого нужна очередь FIFO.

```text
BFS(s):
    visited[s] = true
    dist[s] = 0
    queue.push(s)
    while queue is not empty:
        u = queue.pop()
        for v in adj[u]:
            if not visited[v]:
                visited[v] = true
                dist[v] = dist[u] + 1
                parent[v] = u
                queue.push(v)
```

Критически важно: отмечать `visited[v] = true` при добавлении в очередь, а не при извлечении. Иначе вершина может попасть в очередь несколько раз.

### Инвариант BFS

В очереди вершины расположены в порядке неубывания `dist`. В каждый момент в ней могут находиться вершины не более чем двух соседних слоёв.

### Почему расстояния кратчайшие

Доказательство индукцией по слоям:

1. Для старта расстояние `0` корректно.
2. Пусть расстояния до слоёв `0, ..., k` корректны.
3. Вершина `v`, впервые найденная из слоя `k`, получает расстояние `k + 1`.
4. Если бы существовал более короткий путь, его предпоследняя вершина лежала бы в более раннем слое и обнаружила бы `v` раньше.

Фраза для начала доказательства: «Предположим, что вершина впервые получила расстояние больше истинного, и посмотрим на предпоследнюю вершину кратчайшего пути».

Ограничение: обычный BFS корректен для невзвешенного графа или одинаковых весов рёбер. Для произвольных неотрицательных весов нужен алгоритм Дейкстры.

### Восстановление пути

Идти от конечной вершины по `parent` до `s`, затем развернуть полученную последовательность. Если вершина не была посещена, пути из `s` нет.

## Сложность обходов

При списках смежности DFS и BFS работают за `O(n + m)`:

- каждая вершина обнаруживается один раз — `O(n)`;
- каждый список смежности просматривается один раз;
- суммарная длина списков — `m` для орграфа и `2m` для неориентированного графа.

Дополнительная память — `O(n)`. В рекурсивном DFS сюда входит стек вызовов глубины до `n`.

При матрице смежности перебор соседей всех вершин занимает `O(n²)`.

## DFS и BFS: быстрое сравнение

| | DFS | BFS |
|---|---|---|
| Контейнер | стек / рекурсия | очередь |
| Порядок | максимально в глубину | по слоям |
| Кратчайший путь без весов | не гарантирует | гарантирует |
| Типичный результат | достижимость, порядок обхода | слои, `dist`, `parent` |
| Время со списками | `O(n + m)` | `O(n + m)` |

## Типичные ошибки

- забыть запустить обход из каждой непосещённой вершины при поиске компонент;
- считать ориентированное ребро автоматически двусторонним;
- забыть максимальность в определении компоненты;
- утверждать, что результат DFS не зависит от порядка соседей;
- искать цикл только из одной стартовой вершины;
- считать любое ребро в уже посещённую вершину признаком цикла в ориентированном графе;
- отмечать вершину BFS посещённой только при извлечении из очереди;
- применять обычный BFS к рёбрам разных весов;
- говорить `O(m)`, забывая об изолированных вершинах;
- забывать о возможном переполнении стека в рекурсивном DFS на длинной цепочке.

## Итог в трёх фразах

1. Представление графа определяет стоимость операций с рёбрами и соседями.
2. Цвета DFS позволяют обнаружить цикл в ориентированном и неориентированном графах.
3. BFS обходит граф слоями и находит кратчайшие пути по числу рёбер.
