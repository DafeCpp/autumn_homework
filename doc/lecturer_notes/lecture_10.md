## Откуда начинаем

На лекции 9 пройдена основная часть и введение в Борувку. По изменённому порядку сегодня начинаем потоки и решаем задачу максимального потока; оставшуюся часть Борувки и метрический TSP переносим на следующую пару. Обходы BFS/DFS и понятие разреза графа известны.

Фраза для начала: «В остове разрез помогал выбрать дешёвое ребро. Теперь по ориентированной сети движется поток; выясним, как ограничения дуг ограничивают поток через любой разрез, и найдём максимально возможный поток».

Обозначения: `n = |V|`, `m = |E|`, сеть ориентированная, `s != t`, каждой дуге `e` соответствует конечная ёмкость `c(e) >= 0`. Параллельные и противоположные дуги — самостоятельные объекты с `id`. Петли можно заранее удалить: они не влияют на баланс и значение потока. Для оценки числа увеличений отдельно предполагаем целые ёмкости.

## 1. Сеть и допустимый поток

В ориентированной сети каждой дуге `e` сопоставлена конечная пропускная способность `c(e) >= 0`. Поток `f(e)` задан **на каждой дуге отдельно**, включая параллельные и противоположные дуги:

```text
0 <= f(e) <= c(e)
для каждой v != s,t: сумма входящих f = сумма исходящих f
|f| = сумма исходящих из s f - сумма входящих в s f
```

Значение потока — чистый выход из `s`; по сохранению оно равно чистому входу в `t`. Нулевой поток всегда допустим. Рёбра, входящие в `s` или выходящие из `t`, разрешены: именно поэтому удобно определять значение через разность. Поток может содержать циркуляции, поэтому физический пример с трубами — аналогия, не запрет на циклы.

## 2. Сквозной пример: поток, который пересекает разрез обратно

Дуги записаны как `поток / пропускная способность`:

```text
s → a: 5/6      s → b: 2/2
 a → b: 3/4      b → a: 1/2
 a → t: 3/3      b → t: 4/5
```

Проверить с аудиторией: в `a` входит `5+1=6`, выходит `3+3=6`; в `b` входит `2+3=5`, выходит `1+4=5`. Ограничения ёмкостей выполнены. Значение `|f|=5+2=7`; чистый вход в `t` тоже 7.

Пусть `S={s,a}`, `T={b,t}`. Через границу из `S` в `T` идут `s→b`, `a→b`, `a→t`, их поток равен `2+3+3=8`. Обратно идёт `b→a` с потоком 1. **Чистый** поток через разрез равен `8-1=7`, то есть значению потока. Пропускная способность разреза считается только в направлении `S→T`: `2+4+3=9`.

Вопрос: «Почему сумма исходящего потока 8 не равна значению 7?» Потому что одна единица возвращается обратно через границу. Противоположные дуги — отдельные дуги с отдельными потоками и ёмкостями.

## 3. Теорема о потоке через разрез

`(S,T)` — разбиение всех вершин, где `s ∈ S`, `t ∈ T`. Обозначим:

```text
f(S,T) = сумма f(e) по дугам из S в T
c(S,T) = сумма c(e) по дугам из S в T
```

**Утверждение:** для любого допустимого потока и любого `s–t` разреза

```text
|f| = f(S,T) - f(T,S) <= c(S,T).
```

**Доказательство:** сложим по всем вершинам `S` величину «исходящий поток минус входящий». Для внутренних вершин значение равно нулю, для `s` оно равно `|f|`. Каждая дуга внутри `S` входит в сумму один раз со знаком `+` и один раз со знаком `-`, поэтому сокращается. Остаются дуги через границу: исходящие со знаком `+`, входящие со знаком `-`. Это даёт равенство. Поскольку `f(S,T) <= c(S,T)` и `f(T,S) >= 0`, получаем неравенство.

Следствие: **любой** допустимый поток не превышает ёмкости **любого** разреза. Если найден поток и разрез с равными значениями, поток максимален, а разрез минимален: между ними уже невозможно поместить лучшее значение. Существование такой пары и способ её найти докажем в разделе 5; пока получена только верхняя граница.

## 4. Остаточная сеть и увеличение — 15 минут

Для исходной дуги `e = u→v` с потоком `f(e)` создаём две связанные остаточные операции:

- прямая `u→v` ёмкости `c(e)-f(e)` увеличивает `f(e)`;
- обратная `v→u` ёмкости `f(e)` уменьшает `f(e)`.

Операцию нулевой ёмкости не используем. У каждой исходной дуги своя пара остаточных записей, даже если в исходной сети уже есть другая дуга `v→u`. Например, при `c(e)=5`, `f(e)=3` можно увеличить поток вперёд на 2 или отменить назад до 3.

**Увеличивающий путь** — путь из `s` в `t` по положительным остаточным дугам. Его величина `Δ` равна минимуму остаточных ёмкостей на пути. Применяем каждую операцию на `Δ`: ограничение ёмкости сохраняется, а на каждой внутренней вершине добавленный вход уравновешен добавленным выходом. Значение потока растёт на `Δ`.

### Пример с обратной операцией

Все ёмкости равны 1; исходные дуги:

```text
s→a, s→b, a→x, a→y, b→x, x→t, y→t
```

Сначала увеличим по `s→a→x→t` и получим поток 1. Затем остаточный путь `s→b→x→a→y→t`: шаг `x→a` отменяет единицу на исходной `a→x`. После увеличения поток идёт по `s→a→y→t` и `s→b→x→t`, его значение 2. Разрез `{s}` имеет ёмкость 2, поэтому этот поток максимален по уже доказанной верхней границе.

Вопрос: «Почему без обратной операции мы бы застряли на неудачном первом пути?» Она позволяет отменять ранее сделанный выбор, не нарушая баланс промежуточных вершин.

## 5. Теорема о максимальном потоке и минимальном разрезе

Для допустимого потока эквивалентны:

1. Поток максимален.
2. В остаточной сети нет увеличивающего пути из `s` в `t`.
3. Существует разрез `(S,T)`, для которого `|f| = c(S,T)`.

**1 ⇒ 2.** Если есть увеличивающий путь, увеличение на его положительную остаточную ёмкость даёт поток большего значения — противоречие.

**2 ⇒ 3.** Пусть `S` — вершины, достижимые из `s` по положительным остаточным операциям. Тогда `s ∈ S`, `t ∉ S`. Каждая исходная дуга из `S` в `T` насыщена: иначе её прямая остаточная операция вывела бы в `T`. Каждая исходная дуга из `T` в `S` несёт ноль: иначе её обратная остаточная операция вывела бы из `S` в `T`. Поэтому

```text
|f| = f(S,T) - f(T,S) = c(S,T) - 0.
```

**3 ⇒ 1.** Любой поток не превосходит ёмкости любого разреза. Равенство означает, что текущий поток максимален, а этот разрез — минимален.

Теорема верна и для вещественных ёмкостей; отдельно стоящий вопрос — завершится ли конкретная последовательность увеличений за конечное число шагов.

## 6. Метод Форда—Фалкерсона и получение разреза

Начать с нулевого потока. Пока в остаточной сети есть путь `s→t`, найти его DFS/BFS, вычислить узкое место и увеличить поток. После завершения найти все достижимые из `s` по положительным остаточным операциям вершины — это `S` минимального разреза, `T = V \ S`. Исходные дуги из `S` в `T` составляют разрез.

```text
f[e] = 0 для каждой исходной дуги e
while существует путь P из s в t по положительным остаточным операциям:
    delta = минимум остаточных ёмкостей на P
    for операция r на P:
        если r прямая для e: f[e] += delta
        иначе:               f[e] -= delta
S = вершины, достижимые из s в остаточной сети
output(f, S, V \ S)
```

Каждый поиск пути и обновление занимают `O(n + m)`, хранение сети — `O(n + m)`. Для **целых** ёмкостей каждое увеличение повышает целочисленное значение потока хотя бы на 1; если `F` — значение максимального потока, не более `F` увеличений. С учётом заключительного поиска и инициализации время `O((F + 1)(n + m))`, часто пишут `O(mF)` для связной по активным вершинам сети и `F >= 1`. Величина `F` зависит от чисел во входе, поэтому это не полиномиальная оценка по длине записи ёмкостей.

Для произвольных вещественных ёмкостей нельзя обещать конечное завершение при произвольном выборе путей. Рациональные ёмкости можно масштабировать до целых, но оценка зависит от масштаба. Для гарантированной полиномиальной оценки по числу вершин и рёбер используют, например, Эдмондса—Карпа из резерва.

## 7. Контрольные вопросы

| Вопрос | Ответ |
|---|---|
| Почему через разрез вычитается обратный поток? | он пересекает границу в противоположном направлении |
| Обратная остаточная операция — обязательно исходная дуга? | нет, она отменяет поток на конкретной исходной дуге |
| Почему отсутствие пути означает максимум? | достижимые вершины задают разрез ёмкости `|f|` |
| Почему максимальный поток не больше любого разреза? | чистый поток через разрез равен `|f|` и ограничен его ёмкостью |
| Что гарантирует конечное число увеличений? | целые ёмкости и увеличение минимум на 1; либо конкретный алгоритм с отдельным доказательством завершения |
| Нужно ли считать ёмкость дуг из `T` в `S` в `c(S,T)`? | нет, но их поток вычитается при вычислении чистого потока |

## 8. Резерв на 5 / 10 / 20 минут

### A — 5 минут: Эдмондс—Карп

Искать каждый увеличивающий путь BFS по числу **остаточных дуг**, а не по ёмкости. Для каждого исходного ребра хранить две связанные остаточные записи: при увеличении на `Δ` уменьшить остаток выбранной записи и увеличить остаток её пары. При противоположных исходных дугах пары остаются разными. BFS даёт один путь за `O(n + m)`.

**Точка остановки:** выбор пути определён; доказательства полиномиальной оценки ещё нет.

### B — ещё 5 минут: расстояния BFS не уменьшаются

Пусть `d(v)` — расстояние от `s` до `v` в остаточной сети до увеличения, а `d'(v)` — после. Допустим, какое-то расстояние уменьшилось, и возьмём первую такую вершину `v` на новом кратчайшем пути, `u` — её предшественник. Тогда `d'(u) >= d(u)`, `d'(v) = d'(u)+1`.

Если дуга `u→v` существовала раньше, `d(v) <= d(u)+1 <= d'(v)` — противоречие. Если она появилась только после увеличения, она обратна дуге `v→u` использованного кратчайшего увеличивающего пути, поэтому `d(u)=d(v)+1`. Тогда `d'(v) >= d(u)+1 = d(v)+2` — тоже противоречие. Расстояния до ранее недостижимых вершин не становятся конечными: для первой такой вершины на новом пути аналогично оба случая невозможны.

**Точка остановки:** доказана монотонность расстояний; число увеличений оценим в блоке C.

### C — ещё 10 минут: оценка Эдмондса—Карпа и идея Диница

Назовём остаточную дугу критической, если увеличение насыщает её. В каждом увеличении хотя бы одна дуга критическая. Если та же остаточная запись `u→v` снова становится критической, между этими событиями её обратная запись должна быть использована в увеличивающем пути. В момент первого использования `d(v)=d(u)+1`; к обратному использованию расстояние до `v` не уменьшилось, а дуга `v→u` лежит на кратчайшем пути, так что расстояние до `u` выросло как минимум на 2. Следовательно, каждая из `O(m)` остаточных записей может стать критической `O(n)` раз, всего `O(nm)` увеличений. Каждый BFS и обновление — `O(n+m)`, общая оценка `O(nm(n+m))`, обычно `O(nm²)` после удаления вершин и дуг, не участвующих в путях `s→t` (для активной связной части `n=O(m)`).

**Диниц, только идея:** BFS строит уровни остаточной сети; в слоистой сети оставляем дуги, ведущие с уровня `i` на `i+1`. Затем находим блокирующий поток, уничтожающий все пути `s→t` в слоистой сети, и строим уровни заново. Реализацию и обоснование оценки `O(n²m)` для общего случая оставить на лекцию 11.

**Точка остановки:** определены оба подхода, для Эдмондса—Карпа приведён аргумент оценки; подробный Диниц остаётся впереди.
