# Реализовать алгоритм Джонсона

Дан ориентированный взвешенный граф. Веса дуг могут быть отрицательными. Требуется найти длины кратчайших путей между всеми парами вершин или сообщить, что в графе есть цикл отрицательного веса.

Решение должно использовать **алгоритм Джонсона**: фиктивная вершина, соединённая со всеми вершинами дугами веса 0; Форд—Беллман из неё для вычисления потенциалов `h(v)`; перевзвешивание `w'(u,v) = w(u,v) + h(u) - h(v) ≥ 0`; запуск Дейкстры из каждой вершины и восстановление исходных расстояний `δ(u,v) = δ'(u,v) - h(u) + h(v)`. Теория — в [лекции 8](../doc/lecturer_notes/lecture_08.md), раздел 6 (сценарий в [лекции 7](../doc/lecturer_notes/lecture_07.md), раздел 8, на сокращённом занятии не разбирался).

Ожидаемая сложность — `O(n(n + m) log n)`, при `m ≥ n` это `O(nm log n)` (Дейкстра с бинарной кучей). Решение за `O(n³)` (Флойд—Уоршелл) не засчитывается как алгоритм Джонсона, но им удобно проверять ответы в тестах.

## Формат ввода

В первой строке заданы два целых числа `n` и `m` — количество вершин и дуг (`1 ≤ n ≤ 1000`, `0 ≤ m ≤ 10⁴`).

В следующих `m` строках заданы тройки `u v w` (`1 ≤ u, v ≤ n`, `-10⁶ ≤ w ≤ 10⁶`) — дуга из `u` в `v` веса `w`.

Вершины нумеруются с 1. Допускаются кратные дуги и петли `u = v`. Граф может быть несвязным.

## Формат вывода

Если в графе есть цикл отрицательного веса — **в любой части графа**, даже недостижимый из остальных вершин, — выведите одну строку:

```text
NEGATIVE CYCLE
```

Отрицательная петля `u u w` с `w < 0` тоже является таким циклом.

Иначе выведите `n` строк по `n` значений через пробел. `j`-е значение в `i`-й строке — длина кратчайшего пути из `i` в `j`, либо `INF`, если `j` недостижима из `i`. На диагонали стоят нули.

Сами ответы по модулю не превосходят `(n - 1) · 10⁶ < 2³¹`, но промежуточные величины — расстояния по перевзвешенным весам `δ_h(u,v) = δ(u,v) + h(u) - h(v)` и суммы с «бесконечностью» — выходят за `2³¹`: используйте 64-битные целые.

## Пример 1

Граф из примера B лекций 6–7 (`s = 1`, `a = 2`, `b = 3`, `t = 4`).

Ввод:

```text
4 5
1 2 2
1 3 5
3 2 -4
2 4 3
3 4 6
```

Вывод:

```text
0 1 5 4
INF 0 INF 3
INF -4 0 -1
INF INF INF 0
```

Потенциалы из фиктивной вершины: `h = (0, -4, 0, -1)`. После перевзвешивания все веса неотрицательны.

## Пример 2

Ввод:

```text
3 3
1 2 1
2 3 -2
3 1 -1
```

Вывод:

```text
NEGATIVE CYCLE
```

Цикл `1 → 2 → 3 → 1` имеет вес `-2`.

## Тесты

Примеры входов и ответов лежат в папке `tests` (`*.in` / `*.out`), их можно запустить скриптом:

```bash
python3 scripts/run_cases.py --tasks task_04
```

Помимо этого напишите собственные тесты в `src/test.cpp` (`gtest`). Обязательно покройте случаи:

- отрицательные дуги без отрицательных циклов;
- отрицательный цикл, в том числе в изолированной компоненте и отрицательная петля;
- цикл нулевого веса (это **не** отрицательный цикл);
- кратные дуги и петли неотрицательного веса;
- недостижимые пары (`INF`);
- граф из одной вершины.
