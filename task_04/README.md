# Реализовать алгоритм Джонсона

Алгоритм находит кратчайшие расстояния между всеми парами вершин
ориентированного графа. Веса могут быть отрицательными. Если в любой
компоненте есть отрицательный цикл, матрица расстояний не вычисляется.

## Структура

- `src/main.cpp` — чтение графа и вывод результата.
- `src/graph.hpp` — общие типы `Edge`, `Graph`, `DistanceMatrix` и `INF`.
- `src/bellman.hpp` / `src/bellman.cpp` — Беллман — Форд и проверка отрицательного цикла.
- `src/dijkstra.hpp` — объявления двух версий Дейкстры.
- `src/dijkstra.cpp` — простая версия с линейным поиском ближайшей вершины.
- `src/dijkstra_better.cpp` — версия с `std::set`, используемая Джонсоном.
- `src/johnson.hpp` / `src/johnson.cpp` — объединение алгоритмов.
- `src/test.cpp` — тесты алгоритмов, включая сравнение с Флойдом — Уоршеллом.

Заголовки содержат объявления, `.cpp` — реализации. Единственный `main()`
находится в `main.cpp`. Алгоритмы не читают ввод и не печатают результат,
поэтому их можно вызывать напрямую из тестов.

## Как работает Джонсон

1. Добавляем временную вершину с нулевыми рёбрами во все исходные вершины.
2. Запускаем из неё Беллмана — Форда. Полученные расстояния — потенциалы `h`.
   Если обнаружен отрицательный цикл, возвращаем `false`.
3. Перевзвешиваем исходные рёбра: `w'(u, v) = w(u, v) + h[u] - h[v]`.
   Все новые веса неотрицательны.
4. Запускаем Дейкстру из каждой исходной вершины.
5. Для достижимых пар восстанавливаем расстояния:
   `d(u, v) = d'(u, v) - h[u] + h[v]`.

Временная вершина не входит в результат. Недостижимые пары остаются `INF`.
Расстояния и веса хранятся в `long long`; предполагается, что промежуточные
суммы по модулю меньше `INF = 1000000000000000000LL`.

Для версии с `std::set` время работы — `O(nm + n(n + m) log(n + 1))`,
память с учётом матрицы результата — `O(n² + m)`.

## Ввод и вывод

Ввод: `n m`, затем `m` строк `u v weight`. Вершины нумеруются от `0` до `n - 1`.
Каждое ребро направленное; стартовую вершину вводить не нужно.

Вывод: матрица `n × n`, где строка — начало пути, столбец — конец.
Недостижимая вершина обозначается `INF`. При отрицательном цикле
выводится `Отрицательный цикл`.

Пример ввода:

```text
3 3
0 1 -2
1 2 3
0 2 5
```

Вывод:

```text
0 -2 1
INF 0 3
INF INF 0
```

## Сборка и проверка

Из корня репозитория (нужен установленный GTest):

```sh
cmake -S . -B build
cmake --build build --target task_04 task_04_tests
./build/task_04/task_04
./build/task_04/task_04_tests
```

## Визуализация

Из корня репозитория:

```sh
./visualize task_04
```

Откройте порт 8765 в панели Ports. Выберите один из тестов `task_04`.
На графе показаны исходные веса рёбер. Шаги показывают построение графа,
потенциалы `h` и результат Дейкстры из каждой вершины после восстановления
исходных расстояний. Колонка `from_0` содержит расстояния из вершины 0,
`from_1` — из вершины 1 и т. д.; отсутствие значения означает недостижимость.
Вспомогательная вершина используется только в вычислении потенциалов.
Внутренние релаксации Беллмана и Дейкстры пока не записываются.

Для обновления записей без перезапуска просмотрщика:

```sh
./visualize task_04 --prepare-only
```
