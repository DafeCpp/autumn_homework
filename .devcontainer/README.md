# Окружение C++ в Codespaces

Контейнер использует Ubuntu 24.04. Расширения устанавливаются без закрепления
версий; обновления расширений управляются стандартными настройками VS Code.

## Расширения

- **CMake Tools** — настройка проекта, выбор целей сборки и запуска в нижней строке.
- **clangd** — подсказки, переходы по коду и диагностика. После `CMake: Configure`
  использует `build/compile_commands.json`, включая флаги C++23 и пути GoogleTest.
- **Microsoft C/C++** — отладка через GDB. Его IntelliSense и форматирование
  отключены, чтобы не дублировать выбранные инструменты.
- **Clang-Format** — форматирование C/C++ при сохранении системным
  `/usr/bin/clang-format` по правилам `.clang-format`.

## Компиляторы и библиотеки

Сохраняются пакеты Ubuntu 24.04: GCC 13, Clang 18 и GoogleTest 1.14.
`clang-format` использует версию 18, как проверка форматирования в CI.
`clang-tidy-19` установлен для запуска анализа той же основной версии, что в CI;
встроенная диагностика clangd не обязана полностью совпадать с этим анализом.
Ninja доступен как альтернативный инструмент сборки. Компилятор выбирается
через `CMake: Select a Kit`; смена генератора сборки не навязывается.

Обновления пакетов из репозиториев Ubuntu устанавливаются при выполнении шага
установки пакетов во время сборки образа. Для получения свежего базового образа
и пакетов без использования кеша выберите **Full Rebuild** в диалоге
команды `Codespaces: Rebuild Container`.

## Применение настроек

1. Получить изменения репозитория в Codespace.
2. Выполнить `Codespaces: Rebuild Container`.
3. Выбрать компилятор через `CMake: Select a Kit` и выполнить `CMake: Configure`.
4. Выбрать цель сборки и запуска в нижней строке; сохранить C/C++ файл для
   проверки автоматического форматирования.

При изменении файлов CMake повторить конфигурацию, чтобы clangd получил
обновлённые параметры сборки.
