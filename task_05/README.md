# Задача: Минимальное остовное дерево с ограничением на степень одной вершины

Дан взвешенный связный неориентированный граф, выделенная вершина `s` и целое число `d`. Необходимо найти остовное дерево минимального суммарного веса среди всех остовных деревьев, в которых степень вершины `s` не превышает `d`.

Степень вершины — количество рёбер дерева, инцидентных этой вершине. Степени остальных вершин не ограничены.

Минимум ищется среди деревьев, удовлетворяющих ограничению. Их вес может быть больше веса обычного минимального остовного дерева графа.

### Входные данные

Первая строка содержит четыре целых числа `n m s d`:

- `n` — количество вершин графа (1 ≤ n ≤ 1000).
- `m` — количество рёбер графа (0 ≤ m ≤ 10000).
- `s` — вершина, степень которой ограничена (1 ≤ s ≤ n).
- `d` — максимальная допустимая степень вершины `s` в искомом дереве (0 ≤ d ≤ n − 1).

Далее следуют `m` строк, каждая из которых содержит три целых числа `u v w` — концы ребра и его вес (1 ≤ u, v ≤ n, 1 ≤ w ≤ 1000).

Граф связный. Каждое ребро неориентированное. Допускаются петли и кратные рёбра; каждое кратное ребро задаётся отдельной строкой и имеет собственный вес.

### Выходные данные

Если существует остовное дерево, в котором степень вершины `s` не превышает `d`, выведите минимальный суммарный вес такого дерева.

Если такого дерева нет, выведите:

```text
Невозможно построить остовное дерево с заданным ограничением степени
```

При `n = 1` остовное дерево не содержит рёбер, имеет вес `0` и степень единственной вершины `0`.

### Требования к решению

- Ограничение степени применяется только к вершине `s`.
- Петли не могут входить в остовное дерево.
- Требуется точный алгоритм с полиномиальной сложностью, работающий эффективно при заданных ограничениях.

### Пример 1

Входные данные:

```text
4 4 2 2
1 2 1
2 3 2
2 4 3
1 3 4
```

Выходные данные:

```text
8
```

Обычное минимальное остовное дерево имеет вес `6`, но степень вершины `2` в нём равна `3`. При ограничении `d = 2` оптимально выбрать рёбра `1–2`, `2–4` и `1–3`: их суммарный вес равен `8`.

### Пример 2

Входные данные:

```text
4 3 2 2
1 2 1
2 3 2
2 4 3
```

Выходные данные:

```text
Невозможно построить остовное дерево с заданным ограничением степени
```

Граф уже является деревом, и степень вершины `2` равна `3`. Удаление любого ребра нарушает связность.
