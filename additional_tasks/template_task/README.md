# C. Боггл


**Боггл** (англ. *Boggle*) — настольная игра, в которой обычно играют два человека, составляя слова из имеющихся у них букв и записывая их на бумаге.

---

## Условие

Дана доска Боггл размера N * N и список из M слов. Необходимо проверить, какие из этих слов действительно могут быть составлены на данной доске, и вывести их, сохранив исходный порядок.

Считается, что слово присутствует на доске, если его можно прочитать, переходя от буквы к букве по соседним клеткам (обычно допускаются переходы по горизонтали, вертикали и диагонали), не используя одну и ту же клетку более одного раза в рамках одного слова.

---

## Формат ввода

1. В первой строке записано одно натуральное число N — размер доски.
2. В следующих N строках через пробел записаны буквы — игровое поле Боггл.
3. В следующей строке записано число M — количество слов для проверки.
4. В следующей строке через пробел записаны M слов.

---

## Формат вывода

Выведите через пробел те слова из списка, которые встречаются на данной доске Боггл. Необходимо сохранить их относительный исходный порядок.

---

## Пример

### Ввод

```text
4
M S E F
R A T D
L O N E
K A F B
4
START NOTE SAND STONED
```

### Вывод

```text
NOTE SAND STONED
```
